# Investigative Question Library

This directory contains a catalog of structured investigative prompts and SQL query templates for newsroom budget research.

---

## Catalog Categories

### 1. Year-to-Year Shifts (`year_to_year`)
- Which programs gained the most money?
- Which programs lost the most?
- Which line items are entirely new?
- Which line items disappeared?
- Which items changed by >100% with substantial baselines?

### 2. Internal Reallocation (`internal_reallocation`)
- Which agencies had flat overall budget growth (<5%) but huge internal line item reshuffling?
- Which programs gained money while sibling programs in the same agency lost money?
- Which expense classes (PS, MOOE, Capital Outlays) gained share within an agency?

### 3. Concentration & Geography (`concentration`)
- Which single program accounts for more than 50% of an agency's budget?
- Which regions receive the largest share of infrastructure projects?

### 4. Entity & Rename Detection (`entity_text`)
- Which 2025 items disappeared while a highly similar 2026 description appeared?
- Which project descriptions are repeated identically across multiple regions or engineering districts?

### 5. Infrastructure & Flood Mitigation (`infrastructure`)
- Where did flood control allocations increase the most?
- Which engineering districts account for the largest new flood mitigation projects?

### 6. Journalistic & Evidence Checks (`journalistic`)
- What major budget shifts are hidden behind flat agency headline totals?
- Which findings require cross-referencing with external procurement or audit datasets?
